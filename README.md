## Recent Projects

September and October 2026, newest first. These include games, prototypes, research plans, and curated resources; each description reflects the project's current stage.

- [Open Science Engine](https://github.com/milimithrandir/open-science-engine) — A time-locked backtest where AI agents propose disease hypotheses and later published literature grades them. Early stage; no validated results yet.
- [YOLO](https://github.com/milimithrandir/yolo) — Your Ongoing Life Ontology: weaves your weekly AI threads (Claude, Codex, and others) into a local personal wiki.
- [SUET](https://github.com/milimithrandir/SUET) — Spend Useful Extra Tokens: a fork of V3R1T4S that points idle agent tokens at open problems a computer can check, with four new problem categories.
- [Open AGI Commons](https://github.com/milimithrandir/open-agi-commons) — Turning spare coding-agent sessions into checked improvements to the software around open models: serving, retrieval, memory, reasoning, and tools.
- [Super Intelligence DAO](https://github.com/milimithrandir/super-intelligence-dao) — A DAO any AI agent can join to map and improve the open-source AI stack step by verified step. Phase 0, invite-only.
- [Run Kitty Run](https://runkittyrun.fun) — A 3D kitty runner with solo, local co-op, and online lobbies for up to 32 players, built for fun using a fleet of 10 agents.
- [Emergence Lab](https://github.com/milimithrandir/emergence-lab) — A local research lab where a team of agents chooses questions, runs experiments, and writes reviewed notes within a mission you set.
- [Abyss Drift](https://github.com/milimithrandir/abyss-drift-ascent) — A procedural Three.js eat-or-be-eaten sea game, in an [ascent](https://github.com/milimithrandir/abyss-drift-ascent) build and an [endless](https://github.com/milimithrandir/abyss-drift-infinite) build.
- [Rehost](https://github.com/milimithrandir/rehost) — Old-school custom game lobbies for any browser game, in the spirit of the WC3 custom games screen.
- [DSH Small-Model Lab](https://github.com/milimithrandir/dsh-small-model-lab) — Testing DeepSeek Harness plugin setups on Qwen3-8B, with a [playbook](https://github.com/milimithrandir/dsh-small-model-lab-playbook), follow-up runs ([v3](https://github.com/milimithrandir/dsh-lab-v3), [opus](https://github.com/milimithrandir/dsh-small-model-lab-opus), [opus v2](https://github.com/milimithrandir/dsh-small-model-lab-opus-v2)), and earlier work ([Evolution Lab](https://github.com/milimithrandir/dsh-evolution-lab), [Excalibur loop](https://github.com/milimithrandir/excalibur-harness-loop), [setup](https://github.com/milimithrandir/optimal-deepseek-harness-setup)). Paused; no capability improvement established.
- [Northlight Institute](https://github.com/milimithrandir/northlight-institute) — Deployment and operating setup for a shared OpenClaw assistant on Discord, plus a small institute website.
- [Cursor Ripple](https://github.com/milimithrandir/cursor-ripple) — Tiny native macOS cursor companions that show when Codex or Claude Code is working, needs input, or has an unread response, with a [Claude Code plugin](https://github.com/milimithrandir/cursor-ripple-claude-code).
- [Awesome Disease Knowledge](https://github.com/milimithrandir/awesome-disease-knowledge) — A curated list of disease knowledge bases, evidence maps, and research directories, with source and access notes.
- [Sovereign Agent Cloud](https://github.com/milimithrandir/sovereign-agent-cloud) — A locally verified implementation for dedicated OpenClaw hosting on UpCloud, with billing, metered inference, and portable state. Not yet deployed.
- [Morphostasis Longevity](https://github.com/milimithrandir/morphostasis-longevity) — Early computational research into cellular coordination, bioelectric organization, and aging, with reproducible analysis tools and no validated biological findings yet.
- [Nugget Mode](https://github.com/milimithrandir/nugget-mode) — A format, reusable prompt, and interactive example for presenting complete ideas with expandable context and original sources.
- [Open Source Jigsaw](https://github.com/milimithrandir/opensource-jigsaw) — An AI-assisted research pipeline exploring unusual open-source combinations, with prototype experiments, independent checks, and documented rejections.
- [Ideal Personal Context](https://github.com/milimithrandir/ideal-personal-context) — An open concept for turning personal digital history into a private, portable wiki that gives AI useful context.
- [Wordless Conversation Canvas](https://github.com/milimithrandir/wordless-conversation-canvas) — A prototype that turns live conversation into an animated, wordless scene and lets voice commands reshape it.
- [Jarvis DeepSeek](https://github.com/milimithrandir/jarvis-deepseek) — A local office assistant combining wake-word voice, Codex workers, Mac context, and a TV workspace. Development preview.
- [Awesome BTCFi](https://github.com/milimithrandir/awesome-btcfi) — A sourced directory of Bitcoin finance projects, protocols, and tools, with evidence, lifecycle notes, and trust models.
